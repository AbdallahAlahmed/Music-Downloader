# YouTube Music Downloader

High-quality YouTube Music playlist downloader built with:

- yt-dlp
- FFmpeg
- MP3 conversion
- Metadata embedding
- Cover art support

## Features

- MP3 conversion
- Album art embedding
- Duplicate prevention
- Spotify-style folder structure
- Metadata support

## Installation

```bash
pip install -r requirements.txt
```

Install FFmpeg and update the path in src/config.py.

## Usage

```bash
python main.py
```
